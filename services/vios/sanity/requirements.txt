confluent-kafka     # live-overlay metadata publish/consume (kafka broker, Plan-2)
aiortc              # WebRTC client for webrtc live/replay capture
websockets          # WebRTC signaling
playwright          # headless Chromium: VST-UI capture + PDF rendering (run `playwright install chromium`)
