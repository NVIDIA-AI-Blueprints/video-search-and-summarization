# Perf unit tests (pytest)

Tests for **vss_perf_common** and **vss_perf_lvs_adapter**.

- **expected_result.json** – Mock/reference JSON. The main test asserts that the JSON generated by `build_result()` (from the same dummy test_cases and params) matches this file.
- **test_vss_perf_results_common.py** – `generate_run_id`, `build_result`, `build_and_save`, and **test_generated_json_matches_expected_mock** (generated vs mock).
- **test_lvs_result_adapter.py** – `execution_results_to_test_cases` for file_burst and single_file.

## Run

From `services/video-summarization`:

```bash
PYTHONPATH=perf/benchmark/core pytest --confcutdir=tests/perf tests/perf/ -v
```

Or run `bash tests/perf/run_tests.sh` from any working directory.
