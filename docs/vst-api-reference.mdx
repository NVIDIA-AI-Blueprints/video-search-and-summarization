The VST APIs are the REST interfaces of the Video IO & Storage (VIOS) microservices. They cover managing sensors, streaming live and recorded video, recording, proxy RTSP URLs, and storage. Select an API below for its description and endpoint reference.

- [VST Sensor Management API](/vss/system-components/middleware/video-io-storage-vios/vst-api-reference/vst-sensor-management-api) - Add, discover, and manage sensors and their settings.
- [VST Live Stream Management API](/vss/system-components/middleware/video-io-storage-vios/vst-api-reference/vst-live-stream-management-api) - Live streaming of sensors, for example over WebRTC.
- [VST Replay Stream Management API](/vss/system-components/middleware/video-io-storage-vios/vst-api-reference/vst-replay-stream-management-api) - Replay of recorded video from sensors.
- [VST Record Stream Management API](/vss/system-components/middleware/video-io-storage-vios/vst-api-reference/vst-record-stream-management-api) - Start, stop, and manage recording of sensors.
- [VST Proxy Stream Management API](/vss/system-components/middleware/video-io-storage-vios/vst-api-reference/vst-proxy-stream-management-api) - Manage proxy RTSP URLs for sensors.
- [VST Storage Management API](/vss/system-components/middleware/video-io-storage-vios/vst-api-reference/vst-storage-management-api) - Manage stored media files and storage.
