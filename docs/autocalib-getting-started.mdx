This guide explains how to deploy and access the **Auto Calibration microservice and user interface**.

The detailed Auto Calibration workflow, input requirements, rectification, alignment, results, and troubleshooting content is documented in the [Auto Calibration Workflow Steps](/vss/system-components/calibration/auto-calibration/workflow-steps), [Custom Dataset](/vss/system-components/calibration/auto-calibration/custom-dataset), and [Troubleshooting](/vss/system-components/calibration/auto-calibration/troubleshooting) pages.

## Prerequisites

Before using the VSS Auto Calibration service and UI, ensure you have:

- x86_64 system
- Ubuntu 24.04
- NVIDIA GPU with hardware encoder (NVENC)
- NVIDIA Driver 590 or newer
- Docker configured to run without `sudo`
- NVIDIA Container Toolkit
- An NGC API key with access to the required VSS images

Required calibration inputs and detailed method-specific requirements are documented in [Custom Dataset](/vss/system-components/calibration/auto-calibration/custom-dataset).

## Deployment Steps (Docker Compose)

These steps deploy the Auto Calibration service using the VSS repository.

### 1. Authenticate with NGC

```bash
export NGC_CLI_API_KEY=<NGC_CLI_API_KEY>
export NGC_CLI_ORG='nvidia'
docker login nvcr.io -u '$oauthtoken' -p "${NGC_CLI_API_KEY}"
```

Generate an API key from [NGC Setup](https://org.ngc.nvidia.com/setup) if needed. Do not print or commit the key.

### 2. Clone the VSS repository

```bash
git clone https://github.com/NVIDIA-AI-Blueprints/video-search-and-summarization.git
cd video-search-and-summarization
git checkout tags/v3.3.0
```

### 3. Open the VSS Auto Calibration deployment directory

```bash
cd deploy/docker/services/auto-calibration
```

The directory contains:

```text
compose.yml
ms/compose.yml
ui/compose.yml
```

### 4. Configure the VSS environment

Create `.env` in the current directory:

```dotenv
VSS_AUTO_CALIBRATION_HOST_PORT=8010
VSS_AUTO_CALIBRATION_UI_HOST_PORT=5000
VSS_APPS_DIR=/path/to/video-search-and-summarization/deploy/docker
VSS_DATA_DIR=/path/to/your/data_dir
HOST_IP=<HOST_IP_ADDRESS>
# Optional, uncomment and update this to support RTSP Stream input
# VIOS_BASE_URL=http://<VIOS_HOST_IP>:30888
```

Replace the paths and host address with your values. `HOST_IP` must be reachable from the browser.

This Compose deployment does not start VIOS. To use RTSP capture, deploy VIOS separately and set `VIOS_BASE_URL` to an endpoint reachable from the Auto Calibration container. Otherwise, use file upload.

### 5. Optional VGGT model setup


The Auto Calibration service can run the AMC method without VGGT support. To enable VGGT calibration, download the licensed [VGGT model](https://huggingface.co/facebook/VGGT-1B-Commercial) and place it in `${VSS_DATA_DIR}/auto-calib/vggt/`:
```bash
mkdir -p "${VSS_DATA_DIR}/auto-calib/vggt"
```

You must accept the model license before downloading it.

### 6. Prepare the projects directory

```bash
mkdir -p "${VSS_APPS_DIR}/services/auto-calibration/projects"
sudo chown -R 1000:1000 "${VSS_DATA_DIR}/auto-calib"
sudo chown -R 1000:1000 "${VSS_APPS_DIR}/services/auto-calibration/projects"
```

The Auto Calibration service stores project data in the projects directory and the containers use UID/GID `1000`.

### 7. Start the VSS Auto Calibration service and UI

```bash
docker compose \
  --profile "vss-auto-calibration" \
  --profile "vss-auto-calibration-ui" \
  up -d
```

The microservice is available at:

```text
http://<HOST_IP>:<VSS_AUTO_CALIBRATION_HOST_PORT>
```

The UI is available at:

```text
http://<HOST_IP>:<VSS_AUTO_CALIBRATION_UI_HOST_PORT>
```

With the example values, open `http://<HOST_IP>:5000`.

### 8. Stop the service

```bash
docker compose \
  --profile "vss-auto-calibration" \
  --profile "vss-auto-calibration-ui" \
  down
```
