## Overview

The VSS Alert Bridge verification pipeline processes live RTSP streams through CV detection
and analytics (RTVI-CV and video-analytics microservices) and a VLM stage to classify and
confirm security alerts. Benchmarks measure end-to-end (E2E) latency, VLM and VST stage
latency, and verified alert throughput across the NVIDIA RTX PRO 4500, RTX PRO 6000,
DGX H100 SXM, DGX Spark, and AGX Thor platforms using RT-DETR and Grounding DINO
(GDINO) with Cosmos3 Nano Reasoner (CR3) precision variants.

## Test Configuration

| Parameter | Value |
| --- | --- |
| VSS Release | 3.3 |
| Platforms tested | NVIDIA RTX PRO 4500, RTX PRO 6000, DGX H100 SXM, DGX Spark, AGX Thor |
| CV models | RT-DETR, Grounding DINO (GDINO) |
| VLM | Cosmos3 Nano Reasoner (CR3) |
| VLM precision | BF16, FP8, NVFP4 (platform- and model-dependent) |
| Stream concurrency | 1–50 concurrent RTSP streams (platform-dependent) |
| Configured stream FPS | 10 |
| Video resolution | 1920x1080 (1080p) |
| OSL | 1 |
| Test date | July 2026 |
