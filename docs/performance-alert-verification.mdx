## Overview

The VSS Alert Bridge verification pipeline processes live RTSP streams through CV detection
and analytics (RTVI-CV and video-analytics microservices) and a VLM stage to classify and
confirm security alerts. Benchmarks measure end-to-end (E2E) latency, VLM and VST stage
latency, and verified alert throughput across the NVIDIA B200, DGX H100 SXM, L40S,
RTX PRO 4500, RTX PRO 6000, DGX Spark, and AGX Thor platforms using RT-DETR and
Grounding DINO (GDINO) with Cosmos3 Reasoner (CR3) Nano, Super, and Edge model
variants. Data-center GPU (dGPU) platforms are reported for a single stream; the
edge platforms (DGX Spark and AGX Thor) are reported for single-stream and
multi-stream operation.

## Test Configuration

| Parameter | Value |
| --- | --- |
| VSS Release | 3.3.0 |

| CV models | RT-DETR, Grounding DINO (GDINO) |
| VLM | Cosmos3 Reasoner (CR3) Nano, Super, and Edge (platform- and model-dependent) |
| VLM precision | BF16, FP8, NVFP4 (platform- and model-dependent) |
| Stream concurrency | Varies, see tables below |
| Configured stream FPS | 30 |
| Video resolution | 1920x1080 (1080p) |
| OSL | 1 and 100 |
| Test duration | 1 hour per configuration |
