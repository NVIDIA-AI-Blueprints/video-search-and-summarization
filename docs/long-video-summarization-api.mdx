This page provides API reference for the Video Summarization microservice.

## Base URL

The API is available at:

* **REST API**: `http://<host>:38111`
* **MCP Server**: `http://<host>:38112`

Endpoints listed below with a `/v1` prefix are always served at that path. The rest are served at the root by default and gain a `/v1` prefix when `VSS_API_ENABLE_VERSIONING` is enabled.

## Authentication

The API supports Bearer token authentication. Include your token in the `Authorization` header:

```bash
Authorization: Bearer <your-token>
```

### Summarization

| Method | Endpoint | Summary |
| --- | --- | --- |
| `POST` | `/v1/summarize` | Summarize a video file |
| `POST` | `/summarize` | Summarize a video file |

`/v1/summarize` is always registered. `/summarize` is served as well while
`VSS_API_ENABLE_VERSIONING` is disabled, which is the default.

Both reject a request with HTTP 422 when the media offsets are reversed
(`start` later than `end`) or when `min_tokens` is greater than `max_tokens`.

### Asset Management

| Method | Endpoint | Summary |
| --- | --- | --- |
| `DELETE` | `/assets/{asset_id}/index` | Delete the Elasticsearch index for an asset |

Each summarization request creates one `default_<asset_id>` Elasticsearch index.
Deleting the index for an asset that no longer needs its captions keeps a
long-running deployment from exhausting the per-node shard cap. The call is
idempotent, so a missing index is not an error.
