This reference is generated from the Video Analytics API OpenAPI specification. It includes request parameters, response schemas, and examples for every endpoint.

Generated requests default to direct access at `http://localhost:8081`. For a
self-hosted Docker Compose deployment, replace `localhost` with `HOST_IP` and
use the configured `VIDEO_ANALYTICS_API_HOST_PORT` if it differs from `8081`.
For access through the VSS ingress, use
`http://<HOST_IP>:7777/video-analytics-api` as the base URL, replacing `7777`
with `HAPROXY_HOST_PORT` if it was overridden. Append the documented endpoint
path to the selected base URL.

Select an endpoint in the navigation to jump to its documentation on this page.
