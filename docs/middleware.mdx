The Middleware components provide the storage, messaging, schema, and observability
infrastructure that the VSS microservices and agents depend on.

- [Video IO & Storage (VIOS) ](/vss/system-components/middleware/video-io-storage-vios) - Video ingest, storage, and retrieval services.
- [API Gateway / MCP ](/vss/system-components/middleware/api-gateway-mcp) - Programmatic access to video analytics data and capabilities via REST and MCP.
- [Message Broker ](/vss/system-components/middleware/message-broker) - Exchanges data and control messages between services.
- [NvSchema ](/vss/system-components/middleware/nvschema) - The metadata schema used across the pipeline.
- [Database ](/vss/system-components/middleware/database) - Persistence for analytics, incidents, and verified results.
- [Observability ](/vss/system-components/middleware/observability) - The Grafana, Prometheus, cAdvisor, DCGM Exporter, and Node Exporter stack deployed with the Blueprint.
