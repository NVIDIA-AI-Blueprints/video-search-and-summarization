The Middleware components provide the storage, messaging, schema, and observability
infrastructure that the VSS microservices and agents depend on.

- [Video IO & Storage (VIOS) ](/vss-vios) - Video ingest, storage, and retrieval services.
- [API Gateway / MCP ](/api-gateway-mcp) - Programmatic access to video analytics data and capabilities via REST and MCP.
- [Message Broker ](/message-broker) - Exchanges data and control messages between services.
- [NvSchema ](/NvSchema) - The metadata schema used across the pipeline.
- [Database ](/database) - Persistence for analytics, incidents, and verified results.
- [Observability ](/observability) - The Grafana, Prometheus, cAdvisor, DCGM Exporter, and Node Exporter stack deployed with the Blueprint.
