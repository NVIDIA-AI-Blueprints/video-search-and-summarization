VSS can be deployed in several ways depending on how quickly you want to get started and
how much control you need over the configuration. This page summarizes the available
options, from the native Docker Compose quickstart to fully customizable Docker Compose and
Helm Chart deployments.

## Docker Compose Quickstart

The [Quickstart](/vss/getting-started/quickstart) deploys a basic vision agent with native Docker Compose.
Each profile keeps deployment-specific settings in `user-overrides.env`; the other agent
workflows build on the same Compose pattern for video summarization, search, and alerts.

## Other Deployment Options

- [Brev Launchable](/vss/appendix/additional-deployments/brev-launchable) - A preconfigured, fully optimized NVIDIA Brev compute and software environment that uses the Docker Compose method to stand up the blueprint with minimal setup.
- [Edge Deployment](/vss/appendix/additional-deployments/edge-deployment) - Deploy the base vision agent on edge platforms (DGX Spark, IGX Thor, AGX Thor) using edge-optimized Nemotron LLMs.
- [Helm Deployment](/vss/appendix/additional-deployments/helm-deployment) - Deploy VSS developer profiles on Kubernetes using Helm, the fully customizable alternative to Docker Compose for production and multi-node clusters.
- [Secure Deployment](/vss/appendix/additional-deployments/secure-deployment) - A network-segmentation recipe to follow before exposing VSS in environments where untrusted users, services, or networks may be present.
