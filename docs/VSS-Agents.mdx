Agents built using VSS are AI-powered agents that can perform workflows such as video search, summarization, and reporting through leveraging vision-based tools.

## Deployment Architecture

The VSS Agents are deployed along with the 2D Vision AI with Agents Profile.

![2D Vision AI with Agents Profile](/assets/images/analytics-blueprints/2D-analytics-blueprint-with-agents.png)

Above shows Agents deployed with the 2D Vision AI with Agents Profile.

## Components

- **LLM** ([Nemotron-Nano-9B-v2](https://build.nvidia.com/nvidia/nvidia-nemotron-nano-9b-v2/modelcard)): Reasoning and report generation
- **VLM** ([Cosmos3 Nano Reasoner](https://catalog.ngc.nvidia.com/orgs/nim/teams/nvidia/models/cosmos3-nano-reasoner)): Video understanding
- **VSS Agent**: Orchestrates LLM/VLM to process events and generate reports
- **Reference UI**: Browser-based chat interface using [NeMo Agent Toolkit (NAT)](https://docs.nvidia.com/nemo/agent-toolkit/1.3/) API
