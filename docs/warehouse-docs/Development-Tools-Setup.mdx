1. Check the [system requirements](https://docs.isaacsim.omniverse.nvidia.com/latest/installation/requirements.html).
2. Setup the NVIDIA Isaac Sim

| Feature Support | Isaac Sim 5.1 | Isaac Sim 6.0 |
| --- | --- | --- |
| Data Generation | Yes | Yes |
| Camera Calibration | Yes | Yes |
| Camera Placement | Yes | Yes |

   - [NVIDIA Isaac Sim Quick Installation Guide](https://docs.isaacsim.omniverse.nvidia.com/latest/installation/download.html). Isaac Sim 6.0 is recommended, since this version introduces a new behavior system for characters and forklifts, enabling more realistic and diverse synthetic data generation.

3. Launch **Action and Event Data Generation** in Isaac Sim.

   - For detailed instructions on launching Action and Event Data Generation in Isaac Sim 5.1, refer to [Isaac Sim 5.1 documentation](https://docs.isaacsim.omniverse.nvidia.com/5.1.0/action_and_event_data_generation/index.html#).
   - For Isaac Sim 6.0, refer to [Isaac Sim 6.0 documentation](https://docs.isaacsim.omniverse.nvidia.com/6.0.0/action_and_event_data_generation/index.html#).
