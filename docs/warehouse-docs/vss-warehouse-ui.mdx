This blueprint enables the following components of the [../vss-ui](/vss-ui):

* [Global Chat Sidebar](/vss-ui#global-chat-sidebar) — persistent conversational interface for the Warehouse Agent.
* [Alerts Tab](/vss-ui) — monitor, investigate, and manage AI-detected incidents.
* [Dashboard Tab](/vss-ui) — Kibana dashboard view embedded in the UI.

Use the links above to navigate to the respective documentation.

<Note>
The Global Chat Sidebar is available across multiple tabs and provides an integrated experience. The Search and Video Management tabs are not enabled in the Warehouse Blueprint deployment.
</Note>

### Alerts Tab

The Alerts Tab provides a complete interface for monitoring, investigating, and managing AI-detected incidents in the warehouse. It is organized into a **View Alerts** monitoring dashboard and a **Manage Alerts** view for creating real-time alert rules. Alert rows expose a **Generate Report** action that sends alert metadata to the Global Chat Sidebar so the Warehouse Agent can perform AI-powered analysis with the alert context pre-filled.

![VSS Warehouse BP UI - Alerts Tab](/assets/images/vss-warehouse-bp-ui/vss-warehouse-bp-ui-alerts-mode.png)
