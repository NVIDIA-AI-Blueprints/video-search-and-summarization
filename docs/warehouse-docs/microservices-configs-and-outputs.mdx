This section describes deployment-time settings, runtime configuration, and outputs of the microservices used in the **Warehouse Operations Blueprint**. Use the pages below to configure perception, behavior analytics, alerting, agents, the reference UI, and the VSS Configurator.

## Configuration Guides

| Component | Configuration and Outputs |
| --- | --- |
| [Perception](/vss/vision-agent/agent-workflows/industry-specific-examples/warehouse-operations-blueprint/microservice-configuration/perception) | Configuration and outputs for 2D detection and tracking with RT-DETR, 3D detection and tracking with Sparse4D, and multi-view 3D tracking with MV3DT. |
| [Behavior Analytics](/vss/vision-agent/agent-workflows/industry-specific-examples/warehouse-operations-blueprint/microservice-configuration/behavior-analytics) | Application and analytics settings for processing perception metadata into behaviors, metrics, and safety events. |
| [VSS Configurator](/vss/vision-agent/agent-workflows/industry-specific-examples/warehouse-operations-blueprint/microservice-configuration/vss-configurator) | Profile and sensor configuration flow, environment inputs, stream ceilings, and hardware-specific file changes. |
| [Alerting Service](/vss/vision-agent/agent-workflows/industry-specific-examples/warehouse-operations-blueprint/microservice-configuration/alerting-service) | Warehouse alert verification and real-time alert rules, prompt tuning, and alert delivery. |
| [Agents](/vss/vision-agent/agent-workflows/industry-specific-examples/warehouse-operations-blueprint/microservice-configuration/agents) | Warehouse agent architecture and customization for incident queries, reports, and video analysis. |
| [Reference Agentic UI](/vss/vision-agent/agent-workflows/industry-specific-examples/warehouse-operations-blueprint/microservice-configuration/reference-agentic-ui) | Warehouse chat, alerts, and dashboard views, with example interactions. |

For blueprint architecture and deployment workflows, see the [Warehouse Operations Blueprint](/vss/vision-agent/agent-workflows/industry-specific-examples/warehouse-operations-blueprint). The component guides link to the full service references where applicable.
