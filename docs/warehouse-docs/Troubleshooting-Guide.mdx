## Check containers by profile

Run the following command to inspect container names, images, and status:

```bash
docker ps -a --format 'table {{.Names}}\t{{.Image}}\t{{.Status}}'
```

`Up` means a container is running; `(healthy)` means its configured health check passed. Initialization containers normally finish with `Exited (0)`. An exited container is still listed by `docker ps -a`, so a row alone does not mean it is running. Investigate nonzero exit codes and services that unexpectedly stop or restart. Optional services vary with the selected profile and configuration; a locally hosted NIM appears only when enabled.
