The database layer persists the analytics data produced by VSS, including behavior and metrics data, incidents, and verified results, so that services and agents can search and query it.

- [ELK](/vss/system-components/middleware/database/elk) - Elasticsearch, Logstash, and Kibana: ingest from Kafka or Redis Streams, indexing, retention policies, and dashboards.
