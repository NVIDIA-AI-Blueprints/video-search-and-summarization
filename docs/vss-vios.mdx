Video IO & Storage (VIOS) manages cameras and video for VSS: it ingests live and recorded streams, stores and replays video, and exposes it to other services through REST APIs.

- [VIOS Microservices](/vss/system-components/middleware/video-io-storage-vios/vios-microservices) - Overview and key features: camera discovery, recording, RTSP proxy, and WebRTC/DASH streaming.
- [NVStreamer](/vss/system-components/middleware/video-io-storage-vios/nvstreamer) - Serve video files as RTSP streams to test VIOS without cameras.
- VST API Reference - REST APIs for sensor, live stream, replay stream, record stream, proxy stream, and storage management. Pick one from the navigation, for example [VST Sensor Management API](/vss/system-components/middleware/video-io-storage-vios/vst-api-reference/vst-sensor-management-api).
