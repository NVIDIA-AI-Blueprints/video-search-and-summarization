# Live Filling operation

Use [the QA recipe](deployment/qa/README.md), then open Filling analysis in VSS and choose Live. Bind the supplied Sammy v3 profile to actual VIOS UUID/RTSP values. Older balanced-video calibration is not interchangeable. Inspection never auto-starts.

Select completed bottles to ask the existing chat what happened or compare them. Cycle IDs are inspection records, not vector-search keywords. Receiver timestamps do not certify capture UTC. Replayed RTSP footage is a replay camera.

Toggling the UI tab does not clear sessions or require restarting other services.
