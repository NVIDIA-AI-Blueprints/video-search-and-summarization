Third-Party and External Software Licenses
================================================================================

This file records the direct external software fetched when an operator runs
scripts/train_rl_adapter.ipynb. The setup is off by default. VSS does not vendor
these projects or install them into a VSS image.

NeMo RL is fixed to the commit below. Its uv.lock at that same commit is the
version and hash inventory for packages installed into the NeMo RL driver and
worker environments:
https://github.com/NVIDIA-NeMo/RL/blob/5fb588932bf835506a8a5bac01de4f8c7ab0a065/uv.lock

NeMo Gym creates a separate resource-server environment. The notebook pins the
three packages that its VSS resource server declares directly and records the
complete resolved environment with `uv pip freeze` before baseline measurement.
Other dependencies come from the pinned upstream NeMo RL and NeMo Gym project
metadata and are downloaded by uv at operator execution time.

The model checkpoint, judge service, serving image, and host tools are supplied
by the operator and are not fixed or distributed by this notebook.
