Third-Party Software Licenses
================================================================================

This file contains the licenses and attributions for third-party software
packages installed into the NemoClaw sandbox at deploy time by
scripts/deploy_nemoclaw.ipynb.

These packages are fetched from the npm registry when section 3.7 runs, which
happens only when the operator sets RELAY_OBSERVABILITY=true. The section is
off by default, so a deployment that does not opt in installs none of them.
Because the install happens inside the sandbox rather than through a checked-in
manifest, no lockfile in this repository lists them; this file is the record.

All packages below are published by NVIDIA from a single repository,
https://github.com/NVIDIA/NeMo-Relay, under Apache-2.0, and pinned to 0.7.3 by
the RELAY_RELEASE setting in section 1.3.
