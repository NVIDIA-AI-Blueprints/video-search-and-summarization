Third-Party Software Licenses
================================================================================

This file contains the licenses and attributions for third-party software
packages installed into the NemoClaw sandbox at deploy time by the optional
scripts/deploy_nemo_relay.ipynb notebook.

These packages are fetched from the npm registry only when an operator runs
that notebook with RELAY_OBSERVABILITY=true. The base NemoClaw notebook does
not install them. Because the install happens inside the sandbox rather than
through a checked-in manifest, no lockfile in this repository lists them; this
file is the record.

All packages below are published by NVIDIA from a single repository,
https://github.com/NVIDIA/NeMo-Relay, under Apache-2.0, and pinned to 0.7.3 by
the RELAY_RELEASE setting in deploy_nemo_relay.ipynb.
